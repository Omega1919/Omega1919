## ⚙️ How I Work

1. **Explore** — understand the problem and break the idea into manageable parts.
2. **Plan** — map out the interface, data flow, and implementation approach.
3. **Build** — develop in small, focused steps, using AI tools as collaborators.
4. **Test & debug** — run the app, inspect behaviour, trace errors, and fix issues.
5. **Improve & ship** — refine the experience, use Git for version control, and deploy when ready.

I use AI to accelerate the process, but I stay involved in the decisions, testing, debugging, and direction of the work.
